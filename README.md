In order to run the code, the shell script 'process-file.sh' must be executed with appropriate permissions. The shell script will take in three input arguments: L (the number of integers in the input text file), H (the number of hidden keys in the input file), and PN (the number of processes to generate in the program). The shell script will first make the appropriate files for the program using Makefile. Next, it passes in the input arguments to the file, executing the program with those arguments. Finally, the shell script puts the printf output from the program into an output text file, which is saved in the same directory as it.
